# Adminkopi

**Adminkopi** adalah aplikasi manajemen berbasis web yang dibangun menggunakan [Laravel Nova](https://nova.laravel.com/). Dengan Nova, pengelolaan data menjadi lebih mudah, efisien, dan terintegrasi dengan ekosistem Laravel.

## Fitur Utama

- Antarmuka admin yang intuitif
- Manajemen data yang cepat dan aman
- Integrasi penuh dengan Laravel

## Persyaratan

- PHP >= 8.1
- Laravel >= 10
- Laravel Nova

## Instalasi

Silakan ikuti dokumentasi resmi Laravel Nova untuk instalasi dan konfigurasi lebih lanjut.
